# Wazuh Homelab — SIEM & Security Monitoring Lab

Hands-on cybersecurity lab focused on security monitoring, log analysis, threat detection and incident investigation using Wazuh.

## Overview

This project documents the development of a personal cybersecurity homelab using Wazuh as the main security monitoring and SIEM platform.

The goal is to gain practical experience with:

* Security monitoring
* Log collection and analysis
* Endpoint monitoring
* Detection rules
* Security alerts
* Incident investigation
* Vulnerability detection
* MITRE ATT&CK mapping
* SIEM concepts and workflows
